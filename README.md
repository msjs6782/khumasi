# خماسي — عالم الكلمات

لعبة أندرويد لتخمين كلمة عربية من خمسة أحرف في ثماني محاولات، بلوحة حروف ثلاثية الأبعاد وجزيرة تنمو مع انتصاراتك.

## التثبيت

كل دفعة إلى فرع `main` تُبنى وتُختبر تلقائيًا، ثم يُنشر ملف `khumasi.apk` في صفحة **Releases**.
النسخ الجديدة تُثبَّت فوق القديمة دون فقدان التقدم، لأنها موقعة بالمفتاح نفسه.

## التقنية

- **Kotlin** أصلي، مع **OpenGL ES 3.0** ومحرك 3D خفيف مكتوب للعبة: قطع حروف بحواف مستديرة، وإضاءة وظلال حقيقية (shadow mapping)، ولوح زجاجي ضبابي، وجزيرة منخفضة المضلعات.
- لوحة المفاتيح والواجهة عناصر أندرويد أصلية، لدقة اللمس وصحة اتجاه العربية.
- منطق اللعبة (`core/`) لا يعتمد على أندرويد، وتغطيه اختبارات وحدات.
- إن لم يدعم الجهاز العرض ثلاثي الأبعاد، تعمل لوحة مسطحة بديلة تلقائيًا.

| المجلد | المحتوى |
|---|---|
| `app/src/main/java/com/khumasi/game/core` | القواعد والتقييم والحفظ والإحصاءات |
| `app/src/main/java/com/khumasi/game/render` | المشهد ثلاثي الأبعاد |
| `app/src/main/java/com/khumasi/game/ui` | لوحة المفاتيح والشاشات |
| `dictionary/`, `tools/` | مصادر القاموس وأدوات بنائه |
| `docs/` | قواعد الحروف وسياسة القاموس |
| `ci/` | اختبار الواجهة على محاكي أندرويد |

## البناء والاختبار

```
./gradlew testDebugUnitTest assembleDebug
tools/test_core_locally.sh      # اختبارات المنطق دون Android SDK
```

في كل بناء على GitHub:
1. تُشغَّل اختبارات الوحدات.
2. يُثبَّت التطبيق على محاكي أندرويد، وتُلتقط صور لحالات اللعب، ويُكتب عليه عبر لوحة المفاتيح الحقيقية. تُرفع الصور في أداة `screenshots`.
3. يُنشر الإصدار إذا نجح كل ما سبق.

## مفتاح التوقيع

`signing/khumasi-release.p12` مشفّر (PKCS#12 بـ AES-256). كلمة مروره محفوظة في سرّ المستودع
`KHUMASI_KEYSTORE_PASSWORD` فقط، ولا يُنشر الإصدار بدونها.
**احتفظ بنسخة من كلمة المرور خارج GitHub**؛ فبدونها لا يمكن تحديث التطبيق المثبّت.
